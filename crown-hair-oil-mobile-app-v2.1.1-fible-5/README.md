# Crown Hair Oil — تطبيق الجوال V2.1.1

تطبيق ويب تقدمي (PWA) لمتجر Crown Hair Oil، بواجهة تطبيق جوال حقيقية:
شريط تنقل سفلي، شاشات مستقلة، ويمكن تثبيته على الشاشة الرئيسية في
أندرويد (سامسونج وغيرها) وآيفون عبر "إضافة إلى الشاشة الرئيسية"،
ويعمل دون اتصال بعد أول زيارة.

## التقنية
React 19 · Vite · PWA (Manifest + Service Worker) — بدون أي خادم خلفي.

## الشاشات
- **الرئيسية** — تعريف بالمنتج وفوائده وطريقة الاستخدام.
- **المتجر** — المنتجات مع فلتر تصنيفات، وورقة تفاصيل منتج منزلقة.
- **السلة** — كميات، إجمالي، قاعدة الشحن المجاني، وإتمام شراء بنموذج كامل.
- **الإدارة** — محمية بكلمة مرور (`crown2026`): إضافة/حذف منتجات (مع ضغط
  الصور تلقائياً)، وعرض الطلبات بالحالة والتاريخ.

## منطق المتجر
نفس منطق متجر الويب V2.1.1 (نفس مفاتيح التخزين المحلي ونفس قواعد
الشحن والمخزون): السلة تخزن `{id, qty}` فقط وتُحل من الكتالوج دائماً،
الكميات مقيدة بالمخزون، والبيانات محفوظة في localStorage.

## التشغيل
```
npm install
npm run dev      # للتطوير
npm run build    # نسخة الإنتاج في dist/
npm run preview  # تشغيل نسخة الإنتاج
```
