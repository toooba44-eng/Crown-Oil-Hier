# موقع Crown Hair Oil

## الملفات
- `index.php` — الصفحة التعريفية الرئيسية (القصة، الفوائد، المكونات، طريقة الاستخدام).
- `store.php` — المتجر الإلكتروني (عرض المنتجات، السلة، الدفع، لوحة تحكم لإضافة منتجات وعرض الطلبات).
- `style.css` — جميع الأنماط والتصميم.
- `script.js` — منطق المتجر (المنتجات، السلة، الطلبات، لوحة التحكم).
- `assets/` — الصور الخاصة بالعلامة (الشعار وصور الزجاجة المرفقة).

## كيف تفتحينه محلياً (PHP)
ملفات PHP لا تفتح مباشرة بالنقر المزدوج مثل HTML، لأنها تحتاج خادم PHP يفسّرها أولاً. على جهازك:

1. تأكدي أن PHP مثبّت على جهازك (يأتي افتراضياً مع XAMPP أو MAMP أو Laragon، أو يمكن تثبيته من php.net).
2. افتحي الطرفية (Terminal / موجه الأوامر) وانتقلي إلى مجلد الموقع:
   ```
   cd مسار-المجلد
   ```
3. شغّلي الخادم المدمج في PHP:
   ```
   php -S localhost:8000
   ```
4. افتحي المتصفح على:
   ```
   http://localhost:8000/index.php
   ```

### بديل أسهل بدون سطر أوامر
إذا كنتِ تستخدمين برنامج مثل **XAMPP** أو **Laragon**: انسخي مجلد الموقع كاملاً داخل مجلد `htdocs` (أو `www`)، شغّلي الخادم من لوحة التحكم الخاصة بالبرنامج، ثم افتحي الرابط من المتصفح مثل:
```
http://localhost/crown-hair-oil-website/index.php
```

## لوحة التحكم (المتجر)
في `store.php` يوجد زر دائري ⚙ في الزاوية، يفتح لوحة تحكم محمية بكلمة مرور.

- **كلمة المرور الحالية:** `crown2026`
- لتغييرها: افتحي `script.js` وعدّلي القيمة `ADMIN_PASSWORD` في أول الملف.

من اللوحة يمكنك:
- إضافة منتج جديد (الاسم، الوصف، السعر، السعر قبل الخصم، الكمية، التصنيف، صورة المنتج).
- حذف أي منتج موجود.
- عرض كل الطلبات الواردة من العملاء (الاسم، الجوال، المدينة، طريقة الدفع، الإجمالي).

## طرق الدفع
مفعّلة حالياً: **الدفع عند الاستلام** و **التحويل البنكي**.
خيار **الدفع بالبطاقة (مدى/فيزا)** موجود في الواجهة لكنه معطّل مؤقتاً — لتفعيله فعلياً تحتاجين لربط بوابة دفع حقيقية (مثل HyperPay أو Moyasar أو PayTabs)، وهذا يتطلب خادم/باك إند ولا يمكن تنفيذه بصفحات HTML فقط.

## مهم: تخزين البيانات
بيانات المنتجات والطلبات تُحفظ حالياً داخل متصفح الجهاز نفسه (localStorage)، وليست على خادم مشترك. هذا يعني:
- ما تضيفينه من المتجر على جهازك يظهر لك فقط، ولن يظهر تلقائياً عند عميل يفتح الموقع من جهازه.
- هذا الأسلوب مناسب لتجربة الموقع وتنظيم الفكرة قبل الإطلاق الكامل.
- للانتقال لمتجر حقيقي متعدد الأجهزة (تضيفين منتج من جهازك ويظهر لكل الزوار)، يحتاج الموقع لقاعدة بيانات وخادم فعلي — يمكنني مساعدتك في هذه الخطوة متى احتجتِها.

## التعديلات السريعة
- **الشعار وصور الزجاجة:** استبدلي الملفات داخل `assets/` بنفس الأسماء (logo.jpg, hero-light.jpg, hero-dark.jpg).
- **رابط الموقع والسوشال ميديا:** ابحثي عن `[رابط الموقع]` و `@CrownHairOil_KSA` في `index.php` و `store.php` وعدّليها.
- **رسوم الشحن وحد الشحن المجاني:** في `script.js`، القيم `SHIPPING_FLAT` و `FREE_SHIP_OVER`.
- **المنتج الافتراضي (السعر، الوصف):** في `script.js` داخل `DEFAULT_PRODUCTS`.

## صور الشعر
تم تجنّب استخدام صور بشرية للشعر بناءً على طلبك، واستُخدم بدلاً منها شريط رسومي (خط فني) لخصلات الشعر متناسق مع أسلوب الشعار. إن رغبتِ بصور فوتوغرافية حقيقية لاحقاً، يفضّل استخدام مصادر صور مرخصة للاستخدام التجاري المجاني مثل Unsplash أو Pexels لتفادي أي مشاكل حقوق نشر.
